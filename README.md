# 数学ボード

高校の数学の授業で、生徒の考え（文章・数式・手書きの図・ノートの写真）を集めて比べたり、課題の進み具合を確認したりするWebアプリです。生徒はスマホやPCのブラウザから使います。アプリのインストールは要りません。

## できること

**先生**

- 課題を作る：問題文（`$...$` で数式）、図の画像、ヒントを付けられる
- 個人で提出するか、グループで1つ提出するかを課題ごとに選べる
- 短答の課題は自動で正誤を判定し、正解ならクリアにする（`2√3` と `√12`、`(x+1)^2` と `x^2+2x+1` のように値が等しい答えも正解にできる。形を問うときは完全一致にもできる）
- 記述の課題は、先生が回答を見て「クリア」「再提出」を付け、コメントを返す
- 進捗ボード：生徒×課題の一覧で、未提出・提出済・不正解・再提出・クリアと、生徒の自信度（4段階）が一目で分かる
- 「わからない」と手を挙げた生徒が進捗ボードに出る
- 生徒同士で回答を見せるかを課題ごとに設定できる（見せない／提出後に見せる／いつでも見せる）。生徒同士では常に匿名
- 回答を選んで提示画面（プロジェクター用）に並べる。名前を出すかも切り替えられる
- 授業中にヒントを出す、受付を締め切る
- ランダムなグループ分け、生徒のパスワード再設定、進捗のCSV保存

**生徒**

- 先生が見せる参加コード（QRコード）で、自分で決めたあだ名とパスワードを登録する。2回目からはあだ名とパスワードでログイン
- 文章、数学の記号ボタン、手書き（ペン・直線・消しゴム・方眼）、ノートの写真で回答する
- 自信度を付けて提出する。締切前なら何度でも書き直せる
- グループ課題は、班の誰が提出しても班の回答になる（同時に書き換えて上書きしないよう確認が入る）
- 先生が許可したときは、みんなの考えを匿名で見て「参考になった」を付けられる

本名は保存しません。生徒の情報は、あだ名・出席番号（任意）・パスワード（暗号化して保存）・回答だけです。

## 動かし方

Node.js 22.5 以上が必要です。

```sh
npm install
npm start
```

ブラウザで http://localhost:3000 を開くと、最初に先生のアカウントを作る画面が出ます。データは `data/` フォルダ（SQLite のデータベースとアップロード画像）に保存されます。バックアップはこのフォルダをコピーしてください。

テスト：`npm test`

### 設定（環境変数）

| 変数 | 意味 | 初期値 |
| --- | --- | --- |
| `PORT` | 待ち受けるポート | `3000` |
| `DATA_DIR` | データを保存するフォルダ | `./data` |
| `TRUST_PROXY` | HTTPS の中継（リバースプロキシ）の後ろで動かすときに `true` | なし |
| `COOKIE_SECURE` | ログインの Cookie を HTTPS 限定にするなら `true` | なし |

## インターネットに公開する

生徒のスマホから使うには、インターネットから見えるサーバーに置く必要があります。データをファイルに保存するので、**データが消えない保存領域（永続ディスク／ボリューム）を付けられるサービス**を選んでください。

Docker が使えるサービスなら、付属の `Dockerfile` でそのまま動きます。保存領域を `/data` に付け、`TRUST_PROXY=true` と `COOKIE_SECURE=true` を設定します。

```sh
docker build -t math-board .
docker run -p 3000:3000 -v math-board-data:/data -e TRUST_PROXY=true -e COOKIE_SECURE=true math-board
```

校内のPCで動かして校内Wi-Fiから使う方法もあります（学校のネットワークの規則を確認してください）。

## 構成

- `server/app.js`：API、ログイン、リアルタイム通知（Server-Sent Events）
- `server/db.js`：データベース（Node.js 組み込みの SQLite）
- `server/judge.js`：短答の自動判定（math.js で式を安全に評価）
- `public/`：画面（`index.html` ログイン、`student.html` 生徒、`teacher.html` 先生、`present.html` 提示画面）
