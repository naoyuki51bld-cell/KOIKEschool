# 数学ボード

高校の数学の授業で、生徒の考え（文章・数式・手書きの図・ノートの写真）を集めて比べたり、課題の進み具合を確認したりするWebアプリです。Firebase（無料の Spark プラン）で動きます。先生も生徒もブラウザでURLを開くだけで使え、インストールは要りません。

## できること

**先生**

- 課題を作る：問題文（`$...$` で数式）、図の画像、ヒント
- 個人で提出するか、グループで1つ提出するかを課題ごとに選ぶ
- 短答は自動で正誤を判定し、正解ならクリアにする（`2√3` と `√12`、`(x+1)^2` と `x^2+2x+1` のように値が等しい答えも正解。形を問うときは完全一致も可）。判定は先生の画面が開いている間に行われる
- 記述は回答を見て「クリア」「再提出」を付け、コメントを返す
- 進捗ボード：生徒×課題で、未提出・提出済・不正解・再提出・クリアと自信度（4段階）、「わからない」を押した生徒が分かる。CSVで保存
- 生徒同士で回答を見せるかを課題ごとに設定（見せない／提出後に見せる／いつでも見せる）。生徒同士では常に匿名
- 選んだ回答を提示画面（プロジェクター用）に並べる
- ランダムなグループ分け、生徒のパスワード再設定

**生徒**

- 参加コード（QRコード）で、自分で決めたあだ名とパスワードを登録。2回目からはあだ名とパスワードでログイン
- 文章（数学の記号ボタン付き）、手書き（ペン・直線・消しゴム・方眼）、ノートの写真で回答。自信度を付けて提出
- グループ課題は、班の誰が提出しても班の回答になる
- 先生が許可したときは、みんなの考えを匿名で見て「参考になった」を付けられる

本名は保存しません。生徒の情報は、あだ名・出席番号（任意）・回答だけです。パスワードは Firebase Authentication が管理します。

## しくみ

- `public/`：画面（`index.html` ログイン、`student.html` 生徒、`teacher.html` 先生、`present.html` 提示画面）
- `public/js/store.js`：Firebase とのやりとり。onSnapshot の差分だけで画面を更新するので、無料枠の読み取り回数を使いすぎない
- `firestore.rules`：誰が何を読み書きできるか。生徒が自分でクリアにしたり、他人の回答や名前を見たりできないのは、この規則で守っている
- `public/js/judge.js`：短答の自動判定（math.js）
- 画像は Firestore の文書に入れる（無料プランでは Cloud Storage が使えないため）。写真は送る前に縮小する

## 公開のしかた（ブラウザだけでできる部分）

1. [Firebase コンソール](https://console.firebase.google.com/) でプロジェクトを作る（学校のアカウントで作れないときは個人の Google アカウントで）
2. 「Authentication」→「始める」→「メール / パスワード」を有効にする
3. 「Firestore Database」→「データベースを作成」→ 場所は `asia-northeast1`（東京）、本番環境モード
4. 「プロジェクトの設定」→「マイアプリ」→ ウェブアプリ（`</>`）を追加し、表示された `firebaseConfig` を `public/firebase-config.js` に入れる
5. デプロイ（`npm run deploy`）。Firebase CLI が必要なので、Claude の作業環境など CLI を使える場所から行う
6. 公開されたURL（`https://<プロジェクトID>.web.app`）をすぐに開き、先生のアカウントを作る（最初に作った人が先生になります）

## 開発

```sh
npm install
npm run dev        # エミュレーターで起動 → http://localhost:5000
npm test           # 自動判定とアクセス規則のテスト（Java が必要）
```

localhost で開くと、自動でエミュレーターにつながります。
